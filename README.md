# 🛒 GharTak Grocery - Full Stack MERN App

A full-stack grocery e-commerce web application built using the MERN stack and containerized with Docker for cloud deployment on AWS EC2.

---

## 🚀 Tech Stack

* **Frontend:** React.js, JSX, CSS3
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **DevOps & Cloud:** Docker, Docker Compose, AWS EC2, GitHub Actions (CI/CD)

---

## ✨ Features

* **User Features:** Dynamic product catalog, cart management, and clean user interface.
* **Containerized Microservices:** Isolated Docker containers for Frontend, Backend, and MongoDB.
* **CI/CD Integration:** Automated docker builds and push workflows using GitHub Actions.
* **Cloud Infrastructure:** Hosted on AWS EC2 instance with custom Security Groups & networking.
